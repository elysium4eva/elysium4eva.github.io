算法清单与训练资源

这一节对应课件第二章第 4、6、8 节与第 9 节：三类算法的每一个算法都配了数学公式与应用场景（见课件）， 这里给出可执行的清单——哪个算法配哪个包、用哪个公开数据练。所有链接均为官方主页或官方仓库，课程不提供镜像。

使用原则三条：① 先用公开数据跑通，再换自己的数据； ② 先跑最简单的基线，再上复杂模型；③ 每次只改一个变量，否则不知道是哪个改动起作用。 数据集的许可各不相同，商用前务必读原始许可条款。

一个四周训练路线：① 跑通数据（下载一个品类 + UCI 零售，清洗并画分布）→ ② 类一＋类三（聚类找空档、TOPSIS 排序、敏感性分析）→ ③ 类二＋类四（DID 估增量、回归估弹性）→ ④ 评论与生成（LDA 找主题、ABSA 排痛点、写五点并三层校验）。 每周交付一张图 + 一段结论 + 一个局限，比跑出漂亮数字重要。

环境准备

  1. 安装 Python 3.9 或以上版本（官网下载安装时勾选 “Add Python to PATH”）。
  2. 安装依赖库：pip install requests pandas（中文分词可选：pip install jieba）。
  3. 建议建立三个目录：raw/（原始数据，只读）、clean/（清洗结果）、code/（脚本），保证任何结论都能回溯到原始文件。
  4. 下载本页三份脚本到 code/ 目录，用命令行运行。
