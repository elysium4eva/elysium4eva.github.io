课程程序库

这里放《智能贸易》各章用到的全部程序。每一个都能独立运行，输出是给人看的表格与解释， 而不是一堆数字——目的是让你看清「算法到底在算什么、什么时候会失效」。

运行环境与约定

全部脚本只用 numpy 与 pandas（模块三的三个还需要 requests）， 不依赖 scikit-learn / statsmodels / transformers。 算法用 numpy 手写，是为了让每一步都看得见——需要上工业级库时，脚本注释里会写清替换路径。

# 1. 安装依赖
pip install numpy pandas requests

# 2. 进入 code 目录，直接跑
cd code
python sel_scorecard.py

# 3. 每个脚本顶部都有文档字符串，写清「用途 / 输入 / 输出 / 依赖 / 对应课件章节」
python -c "import sel_scorecard; print(sel_scorecard.__doc__)"
约定：所有脚本内置的示例数据都是教学用合成数据， 不对应任何真实商品、店铺或 ASIN。换成自己的数据时，只需替换脚本顶部的那几个变量。

合规声明

三条边界，请在使用前读一遍：
1. 不做未授权抓取。凡涉及平台数据的脚本，输入都必须是官方 API 返回、后台导出或授权数据商的产物； 课程不提供任何绕过反爬的方法。
2. 不保存受限字段。地图类 API 的条款通常只允许长期保存有限字段， 脚本默认只落盘 place_id / 名称 / 网址，其余字段请当场核对、不要入库。
3. 示例数据全是编的。所有内置样例（商品、评论、竞品、BSR）均为教学合成， 不对应真实主体；结论只能用于理解方法，不能当作市场判断。
怎么用这些程序最有效：不要只跑一遍看输出。挑一个脚本，改三个地方再跑—— 换个品类的数据、改一个阈值、把权重调一次——对比输出怎么变。方法感是改出来的，不是读出来的。
